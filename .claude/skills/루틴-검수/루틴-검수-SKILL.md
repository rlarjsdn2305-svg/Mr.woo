# 루틴 검수 기준 (Trainer Woo)

디자인·레이아웃·구조는 변경하지 않는다. **내용(종목 구성·문구·강도·표현)만** 검수·수정한다.
핵심 철학: "선택지는 풍부하게, 목적은 선명하게." / "정렬을 고치는 게 아니라 움직임과 부하를 조절한다."

## 절대 원칙
- HTML/CSS/색상/레이아웃/카드 구조 변경 금지. 문서 구조 유지, 내용 문구·종목 구성만 수정.
- 위험하거나 단정적인 표현 제거. "나쁜 자세", "무조건 교정", "통증의 원인" 식 단정 금지.
- 자세 정렬보다 **움직임 조절·보상 패턴·부하 관리·피로 누적** 중심으로 설명.
- 통증 원인을 단일 자세·특정 정렬로 단정하지 않는다.
- 회원 수준·목적·통증 이력·수행 능력에 따라 반복수·난이도가 조절되도록.
- 현재 센터에서 수행 가능한 기구·환경 기준.

## 1. 택1 계열 정합성
같은 계열끼리만 묶는다. 기준: 관절 움직임 / 주동근 / 부하 방향 / 안정성 요구도 / 피로 양상 / 목적 / 난이도.
- 복합운동과 고립운동을 한 택1 그룹에 섞지 않는다.
- 계열 구분: 수평프레스 / 인클라인프레스 / 가슴플라이 / 수직프레스 / 수직당기기 / 수평당기기 / 고관절힌지 / 무릎우세(스쿼트) / 편측하체(런지) / 측면하체 / 햄스트링고립 / 측면어깨 / 후면어깨.
- 잘못된 예: 힙쓰러스트/스플릿데드리프트 묶기, 스쿼트/RDL/레그컬 묶기, 로우/암풀다운 묶기.

## 2. 운동 다양성 (계열 안에서 확장)
- 같은 계열 안에서 도구·궤적·부하 방향을 변주해 **선택지를 풍부하게** 제공(지루함 감소, 기구 대기 대응, 컨디션별 선택, 다양한 궤적 경험, 지속률 향상).
- 인간은 다양한 궤적의 움직임을 추구하는 것이 이롭다 — 웨이트라도 많은 궤적·각도·면을 경험하게 한다. (단정적 효과 아닌 원리)
- 단, 계열을 흐트러뜨리지 않는다. 당일에는 한 계열 중 1개만 수행. 한 세션 총 종목 수를 과도하게 늘리지 않는다.
- 회원 수준에 맞지 않는 고난도 선택지는 제외하거나 '상급자 선택'으로 분리.

## 3. 수준별 반복수·세트·RPE
- 초급: 메인복합 10~15 / 보조 10~15 / 고립 12~20 / RPE 6~8. 저반복 고중량 금지. 머신·덤벨·체중 우선. 동작 학습·반복 품질 우선.
- 중급: 메인복합 6~10 / 보조 8~12 / 고립 10~20 / RPE 7~9. 숙련도 따라 바벨 허용.
- 상급: 메인복합 3~8 / 보조 6~12 / 고립 10~20 / RPE 7~9. 단 데드리프트·OHP·바벨로우 등 기술 붕괴 빠른 종목은 6~8회가 더 적절.
- 4~6회는 기본값이 아니라 숙련자 선택값. 숙련도 불명확하면 8~12회. 고급자라도 통증·피로 시 반복수↑ RPE↓.
- RPE 일괄 적용 금지. 기술운동(데드·스쿼트·OHP)은 실패지점까지 밀지 않는다.

## 4. 통증·정렬 표현 정밀화 (핵심)
- **골반 전·후방경사**: 나쁜 자세로 단정 금지. 문제는 각도가 아니라 고관절 대신 **요추의 과도한 굴곡·신전 보상** 반복. → 골반 움직임과 요추 움직임을 구분해 조절.
- **힙쓰러스트·데드 락아웃**: 문제는 고관절 신전·골반 후방경사 자체가 아니라 **요추 과신전으로 젖히는 보상**. 락아웃은 허리 젖히기가 아니라 둔근 수축으로 고관절 신전 마무리. 흉곽 들림·허리 꺾임 보상 시 가동범위·중량 조절.
- **오버헤드프레스**: 바 앞쏠림·팔꿈치 벌어짐을 '흉추 신전 부족'으로 단정 금지. 흉곽 확장·흉추 신전·견갑 상방회전·전거근·광배/대흉근 긴장·그립폭·바패스·복압 등 복합 원인. → 호흡으로 흉곽 확장 후 흉추신전·견갑 상방회전 확인, 그립 조절 또는 덤벨 전환.
- **랫풀다운·로우**: 단순 '어깨 내리고 모으기' 대신, 흉곽 세우고 흉추 신전 확보 → **견갑골이 갈비뼈 위에서 안정적으로 미끄러지는** 상태에서 팔꿈치를 몸통으로. 과도한 견갑 후인·요추 과신전 보상 금지. 흉곽-골반 연결 유지.
- **가슴 프레스 '어깨 말림'**: 단순 견갑 전인이 문제가 아니라 **상완골두 전방활주·견갑 전방경사·하각 들림**을 의심. '전인=문제'로 표현 금지. 견갑이 갈비뼈 위에서 안정적으로 움직이고 어깨 전면 압박 없이 진행되는지로 판단.
- **스탠스·발끝**: 외회전은 '1번 발가락 과부하 방지'가 목적이 아니라 **고관절이 열리고 무릎이 발 방향과 정렬**되게 돕는 조정값(15~30도 참고값, 개인차). 엄지·새끼·뒤꿈치 삼각 지지 + 중족골 고른 압력. 발가락으로 움켜쥐기보다 넓게 누르기.
- **맨발·미니멀 슈즈**: 무지외반증이라도 일괄 권장 금지. 발 통증·중족골·족저근막·발목 불안정 시 안정적 신발.

## 5. 워밍업·유산소·참고문헌
- **워밍업**: 구체 드릴 나열 대신 목적 중심 간결 표기. 예) 하체="호흡 정리 + 복압 형성 + 고관절 회전 + 발 접지", Push="흉곽 확장 + 흉추 신전 + 견갑 상방회전", Pull="흉추 신전 + 견갑 안정화 + 당기기 준비". 구체 드릴은 Trainer Tips에 선택 예시로만.
- **유산소**: 고강도 고정 금지. 감량=Zone2 15~25분, 근비대=10~15분 선택, 하체 피로/무릎·발목 부담 시 사이클·걷기, 고강도 인터벌 주1~2회 선택. 웨이트 퍼포먼스 저하 시 고강도 축소.
- **참고문헌**: 특정 큐잉의 직접 근거처럼 과장 금지. "넓은 주제의 참고자료"로 표현. 실존 확인 규칙은 에이전트.md 및 CLAUDE.md 상속 — 재서술하지 않는다.

## 6. 전체 톤
- 금지어: 무조건 / 반드시 교정 / 나쁜 자세 / ~의 원인입니다 / 전방경사는 문제 / 후방경사는 문제 / 중립만 유지 / 전인은 피해야 / 맨발이 더 좋습니다 / 이 자세가 정답 / 골반이 틀어졌습니다 / 라운드숄더 때문에 통증 / 흉추 신전 부족이 원인.
- 권장어: 조절합니다 / 구분합니다 / 확인합니다 / 보상이 커지면 조절합니다 / 개인 구조·컨디션에 따라 다를 수 있습니다 / 통증·불편 시 대체합니다 / 정렬보다 움직임 조절·부하 관리가 중요 / 요추 보상이 커지지 않도록 확인 / 흉곽과 골반 연결 유지 / 견갑골이 갈비뼈 위에서 안정적으로 움직이는지 확인.

## 7. 최종 검수 체크리스트
1. 택1이 같은 계열로 묶였는가
2. 선택지는 다양하되 계열이 흐트러지지 않았는가
3. 수준에 맞지 않는 저반복 고중량이 없는가
4. 수준별 반복수·RPE가 조절되었는가
5. 골반 전·후방경사를 나쁜 자세로 단정하지 않았는가
6. 요추 보상·흉곽 조절·견갑 움직임을 구분했는가
7. 전인과 전방활주를 혼동하지 않았는가
8. 워밍업이 목적 중심인가
9. 발끝 방향·발 압력 설명이 정확한가
10. 락아웃 문제를 요추 보상으로 설명했는가
11. 맨발·미니멀 슈즈를 과도하게 일반화하지 않았는가
12. 유산소가 웨이트 회복을 방해하지 않게 조정됐는가
13. 참고문헌을 과장하지 않았는가
14. 회원도 이해 가능하고 트레이너도 운동역학적으로 납득 가능한가
15. '자세 교정 문서'가 아니라 '움직임 조절·부하 관리 중심 가이드'인가
