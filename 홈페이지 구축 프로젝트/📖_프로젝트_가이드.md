## 🎮 가장 중요한 기본기 : 미리보기 하는 법

> 홈페이지를 고치면 **내 컴퓨터에서 먼저 눈으로 확인**할 수 있습니다. 이걸 "미리보기(개발 서버 실행)"라고 합니다. 인터넷에 올리는 게 아니라, 나만 보는 연습용 화면입니다.

### ▶️ 미리보기 켜기 (3단계)

**1단계 — 폴더에서 터미널 열기**
- `홈페이지 구축 프로젝트` 폴더를 엽니다.
- 폴더 빈 공간에서 **`Shift` + 마우스 우클릭** → **"여기에 PowerShell 창 열기"** 클릭
- (또는 VS Code를 쓴다면: 이 폴더를 열고 상단 메뉴 `Terminal → New Terminal`)

**2단계 — 실행 명령어 입력**
검은 창에 아래를 그대로 입력하고 `Enter`:
```
npm run dev
```

**3단계 — 브라우저에서 보기**
- 잠시 기다리면 `Local: http://localhost:3000` 같은 글자가 나옵니다.
- 크롬 같은 브라우저 주소창에 **`localhost:3000`** 을 치고 들어가면 → 내 홈페이지가 보입니다! 🎉

### ⏹️ 미리보기 끄기
- 명령어를 입력했던 그 검은 창에서 **`Ctrl` + `C`** 를 누르면 꺼집니다.
- ⚠️ **중요:** 이 창을 켜둔 채로는 폴더 이름 변경/이동이 안 됩니다. (저번에 폴더가 "열려있다"고 한 게 바로 이것 때문이었어요.) 작업 끝나면 꼭 `Ctrl+C`로 꺼주세요.

### 💡 미리보기의 마법
- 미리보기를 켜둔 상태에서 글자나 가격을 고치고 저장하면 → **브라우저가 자동으로 새로고침** 되며 바로 반영됩니다. 고치고 → 저장 → 화면 확인. 이 반복이 전부입니다.

## 🆘 자주 막히는 것 & 해결법

| 증상 | 해결 |
|------|------|
| `npm run dev` 했더니 빨간 글씨(에러)가 떠요 | 그 빨간 글씨를 복사해서 "메이데이, 이 에러 뭐야?" 하고 붙여넣기 |
| 폴더 이름/이동이 안 돼요 ("사용 중") | 미리보기 검은 창에서 `Ctrl+C` 로 끄기 |
| `localhost:3000` 들어가도 안 떠요 | 검은 창에 `Local: http://...` 글자가 나왔는지 확인. 안 나왔으면 아직 켜지는 중 |
| `npm` 이라는 명령어를 모른대요 | Node.js가 안 깔린 것. "메이데이, Node 설치 도와줘" |
| `스크립트를 실행할 수 없으므로 npm.ps1 ...` 빨간 글씨 (PSSecurityException) | 보안 설정이 막은 것. 검은 창에 `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` 입력 → `Y` → 다시 `npm run dev`. **한 번만 하면 됨** |
| 뭘 고쳤는데 화면에 반영이 안 돼요 | 파일을 **저장(Ctrl+S)** 했는지 확인. 브라우저 새로고침(F5) |
