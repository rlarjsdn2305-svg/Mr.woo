> 최상위 `Mr.woo\\\\CLAUDE.md`에 있습니다. 본 문서는 그 위에 더해지는 \\\*\\\*프로젝트 전용 규칙만\\\*\\\*

> 메이데이 · 도파민 · 브릿지 부서는 이 프로젝트에서 작업하기 전 본 문서를 먼저 읽고 따릅니다.

\---

## 1\. 프로젝트 개요

* **목적:** PT 회원별 맞춤 루틴을 모바일 반응형 HTML 자료로 자동 생성.
* **단계:** 1차 목표 — 자동 생성 시스템 안정화.
* **주담당:** 메이데이(HTML 생성 · 구조 보존). **검수:** 브릿지(고객 관점). 필요 시 도파민(표현 · 큐잉).
* **프로젝트 자산:**

  * `template.html` — HTML 자료 기준 템플릿 (모든 HTML 생성의 출발점)
  * 루틴설계 에이전트
  * 스킬 3종: `pt-루틴-html-자료` / `큐잉-원칙` / `루틴-검수`
  * `산출물\\\\` — 생성 결과물 보관 폴더

\---

## 2\. 작업 흐름

```
회원 정보 입력
  → 루틴설계 에이전트 (목적 · 레벨 · 통증 · 제약 분석)
  → 루틴-검수 스킬 (검수 · 수정)
  → pt-루틴-html-자료 스킬 (HTML 생성)
  → 산출물\\\\ 저장
```

* 작업 → 검수 → 수정 → 재검수 → 사용자 최종 확인 흐름을 유지한다.

\---

## 3\. 루틴 설계 규칙

* 사용자가 제공한 회원 정보만 사용한다. 입력에 없는 내용은 만들지 않는다.
* 작업 시작 전 **운동 목적 · 레벨 · 주당 횟수 · 1회 시간 · 통증 · 부상 · 제약 · 체형 특이사항**을 먼저 요약한다.
* 케렌시아 주안간석점 **사용 가능 운동 화이트리스트** 안에서만 종목을 선택한다.
* 택1 구조는 같은 계열끼리만 묶는다.
* 초급자는 안정적이고 이해하기 쉬운 운동을 우선한다.
* 반복수와 RPE는 레벨에 맞춰 조정한다.

\---

## 4\. 큐잉 · 표현 금지 항목

* 통증의 원인을 단정하지 않는다.
* 골반 전방경사 · 후방경사를 나쁜 자세로 표현하지 않는다.
* 복압을 의식적으로 잡으라는 표현을 기본 큐잉으로 사용하지 않는다.

\---

## 5\. HTML 자료 제작 규칙

* `template.html`을 기준으로 한다. CSS · 클래스 · 레이아웃 · 디자인 구조를 임의로 새로 만들지 않는다.
* 기존 템플릿을 복제하고 **텍스트만 치환**한다.
* 모바일 기준 `max-width: 430px` 구조를 유지한다.
* 아래 정식 클래스를 유지한다.

  `cover` · `rpe-card` · `wtable-card` · `wtd-part` · `ex-tag` · `day-section` · `tips-wrap` · `refs` · `doc-footer`

* DAY별 아코디언과 Trainer Tips 아코디언 구조를 유지한다.
* 루틴 개요 · RPE 가이드 · Trainer Tips · 참고 문헌의 제목 형식을 통일한다.
